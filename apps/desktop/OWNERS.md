# desktop

- **Owner:** desktop workstream (spec Agent 2)
- **Purpose:** the ONE wOS Desktop (D16, Electron + React): an app shell (wOS account, Settings -> Environment, organizations, Your Apps / Available Apps, the signed-module installer) with Build built in. Main owns processes, git and fs via the orchestrator (Build only, under S-40); renderers are sandboxed; module pages run under `wos-module://` in their own view.
- **Contracts:** consumes `@waronsaas/contracts` 5.8.0 (WORKSTREAMS 12.4 desktop row: AppRoutes, EnvironmentDescriptor, ActiveApps, ModuleBundle, ModuleInstallMachine, CoreRoutes local sign-in; Orchestrator for Build) and the orchestrator's exported `createSessionReader`; changes to shared contracts go through an ARCHITECTURE_BLOCKER (`docs/architecture/WORKSTREAMS.md` section 4).
- **Done means:** the DONE list for this workstream in `docs/architecture/WORKSTREAMS.md`.
- **Layout:** `src/main` (the shell: core, environment, platform client, module installer, module view and `wos-module://` protocol, S-40 handler registry, security, Windows-aware paths; `keys/module-signing-keys.json` holds the PINNED module-signing public keys, empty until the coordinator pins real ones with `scripts/pin-module-key.mjs`), `src/apps/build` (Build: `wos-app.json`, `main/` handlers, `renderer/` screens), `src/preload` (`index.ts` the shell's bridge, `module.ts` a module page's `window.wos.app`; each a single CommonJS file), `src/renderer` (the shell's React UI, no Node, strict CSP), `src/shared/ipc.ts` (`WosBridge`, channel groups), `dev/` (fake control plane, fake registry, entitlements and Cores, throwaway-key test module; never packaged), `build/` (icons generated by `npm run icons`).
- **Commands (from the repo root, after `npm run build`):** `npm test -w apps/desktop`, `npm run typecheck:test -w apps/desktop`, `npm run start:fake -w apps/desktop` (the app against the fake control plane; sign-in code ABCD-EFGH), `WOS_SHOTS_DIR=<dir> npx electron apps/desktop/dist/app/main-fake.mjs` (screenshots), `npm run dist:mac|dist:win|dist:linux -w apps/desktop` (CI only for signed builds, D7, S-42; a local `electron-builder --mac dir` with `CSC_IDENTITY_AUTO_DISCOVERY=false` packages unsigned), `npm run icons -w apps/desktop` (re-renders every icon from the wOS mark).
