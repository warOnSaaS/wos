# Dogfood logs

One file per workstream, `docs/dogfood/<workstream>.md`, owned by that workstream (WORKSTREAMS.md rule 9). One row per working session: date, context size at start, task scope, files owned, files changed, duration, blockers, merge conflicts, repair loops, verification failures, integration failures, lessons. The architect summarises them at each wave gate as evidence of missing wOS capabilities.
